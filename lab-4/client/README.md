# Клиент приложения для управления цехами и датасетами

Клиентская часть приложения для управления цехами и датасетами, включающая интерфейс для аутентификации, работы с пользователями, цехами и датасетами.

## Технологии

- React
- React Router
- Axios
- Tailwind CSS

## Установка и запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите приложение в режиме разработки:

```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Структура проекта

- `src/` - исходный код приложения
  - `components/` - компоненты приложения
  - `contexts/` - контексты React
  - `pages/` - страницы приложения
  - `App.js` - главный компонент приложения
  - `index.js` - точка входа

## Роли пользователей

- Начальник цеха - может просматривать и редактировать назначенные ему датасеты
- Диспетчер - может назначать датасеты цехам
- Администратор - имеет полный доступ к управлению системой
