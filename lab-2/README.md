# Генератор задач оптимизации

Данное приложение представляет собой Python-аналог программы generator.pas для генерации тестовых данных задач оптимизации с графическим интерфейсом пользователя.

## Возможности программы

- Создание серии задач линейного программирования для нескольких временных интервалов
- Ввод размерностей задач и параметров через удобный интерфейс
- Формирование матриц коэффициентов, векторов ограничений и целевых функций
- Расчет промежуточных параметров и оптимальных планов
- Сохранение результатов в текстовые файлы
- Отображение процесса генерации в реальном времени с использованием индикатора прогресса

## Требования

- Python 3.6 или выше
- Библиотеки:
  - NumPy
  - tkinter (входит в стандартную библиотеку Python)

## Установка

1. Убедитесь, что у вас установлен Python 3.6 или выше
2. Установите необходимые библиотеки:
   ```
   pip install numpy
   ```
3. Скачайте файл `generator.py`

## Запуск программы

```
python generator.py
```

## Использование

1. Введите количество временных интервалов и число решаемых задач
2. Нажмите кнопку "Начать генерацию"
3. Следуйте инструкциям программы для ввода необходимых данных:
   - Введите размерности задач (N и M)
   - Введите компоненты плана X для первой задачи
   - Введите элементы матрицы A
   - При необходимости введите deltaB для последующих задач
4. Программа создаст файлы с результатами в текущей директории с именами `out_L_K.txt`, 
   где L - номер интервала, K - номер задачи

## Структура программы

- Класс `OptimizationGenerator` содержит всю логику работы приложения
- Метод `start_generation()` реализует основной алгоритм генерации, аналогичный программе на Pascal
- Для ввода данных используются модальные диалоговые окна
- Ход выполнения отображается в текстовом поле и с помощью индикатора прогресса
