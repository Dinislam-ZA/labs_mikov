# Генератор задач оптимизации (Kotlin/TornadoFX)

Данное приложение представляет собой Kotlin-аналог программы generator.pas для генерации тестовых данных задач оптимизации с графическим интерфейсом пользователя. Реализация использует библиотеку TornadoFX, основанную на JavaFX.

## Возможности программы

- Создание серии задач линейного программирования для нескольких временных интервалов
- Ввод размерностей задач и параметров через удобный интерфейс
- Формирование матриц коэффициентов, векторов ограничений и целевых функций
- Расчет промежуточных параметров и оптимальных планов
- Сохранение результатов в текстовые файлы
- Отображение процесса генерации в реальном времени с использованием индикатора прогресса

## Требования

- JDK 11 или выше
- Gradle для сборки проекта

## Установка и запуск

### Вариант 1: Запуск из IDE

1. Откройте проект в IntelliJ IDEA или другой IDE с поддержкой Kotlin
2. Убедитесь, что Gradle успешно импортировал зависимости
3. Запустите файл `Generator.kt`

### Вариант 2: Запуск из командной строки

1. Убедитесь, что у вас установлен Gradle
2. В корневой директории проекта выполните:
   ```
   ./gradlew run
   ```
   или для Windows:
   ```
   gradlew.bat run
   ```

## Структура проекта

- `Generator.kt` - основной файл программы, содержащий весь код приложения
- `build.gradle.kts` - файл сборки Gradle с настройками проекта и зависимостями

## Особенности реализации

- Использование DSL TornadoFX для создания пользовательского интерфейса
- Асинхронное выполнение длительных операций с использованием `runAsync`
- Модальные диалоги для ввода данных
- Функции для создания диалогов разных типов: ввод числа, вектора, матрицы

## Функциональность

Программа полностью повторяет логику оригинальной Pascal-версии:
1. Пользователь вводит количество временных интервалов и число задач
2. Для каждого интервала и задачи:
   - Задается размерность задачи (N и M)
   - Вводится план X для первой задачи
   - Вводится матрица A для первого интервала
   - Для последующих задач и интервалов значения вычисляются на основе предыдущих с учетом deltaB
3. Результаты записываются в файлы `out_L_K.txt`, где L - номер интервала, K - номер задачи
